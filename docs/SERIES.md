# 系列文章大纲：《茶：我用 TypeScript 写了一门编程语言》

> 每一章 = 一个可运行的里程碑 + 一个独立的博客文章。
> 原则：不抄 Crafting Interpreters 的行文，讲自己的取舍和踩的坑；每篇开头放一段能跑的代码。

## 第 1 章：语言设计图纸 —— 在写第一行代码之前

- 目标定级：这门语言解决什么问题？（答案：没有问题，它是玩具，但玩具也要有品味）
- 语法取样：为什么是 C 家族大括号而不是 Python 缩进 / Lisp 括号
- 关键决定清单：动态类型、Lox 风格真值（0 为真）、严格 `+`、深相等、中文标识符
- 产出：完整 EBNF 文法 + 「特性拒绝清单」（明确不做什么）
- 素材：cha-lang 第一条 commit 前的空白 README

## 第 2 章：词法分析器 —— 字符流的炼金术

- 手写 vs 正则：为什么不用正则一把梭
- 数字、转义、行号列号追踪（报错体验的一半在词法器里）
- **重头戏：模板字符串插值** —— 字符串与代码两种模式互相递归，
  `${}` 里的字符串里还能再 `${}`，怎么用「token 数组挂标记」实现零歧义
- 已知歧义展示：`"${1 + 2"` 为什么没法区分收尾引号（留坑给第 8 章）
- 彩蛋：嵌套块注释 + 中文标识符（CJK 判定的一个字符集细节）
- 素材：29 个词法测试用例的演进史

## 第 3 章：解析器 —— 递归下降与优先级链

- 递归下降为什么「降」：优先级链函数的调用方向
- 赋值语句的经典难题：左值怎么解析（先当表达式、再回改写 Assign）
- `a[i] = x` 与 `m.k = x`：三种赋值目标的统一处理
- map 与代码块的 `{}` 歧义：JS 是怎么解决的，我们照抄 + 说明理由
- print 为什么从关键字降级成内建函数（设计返工实录）
- 素材：优先级链 5 个函数、32 个解析测试

## 第 4 章：求值器 —— 树遍历与环境链

- Expr → Value 的大 switch：为什么树遍历是最被低估的求值方式
- 环境链（Environment）：作用域就是一条链表
- 用异常实现 return/break/continue：非局部跳转的工程取舍
- and/or 返回操作数本身：Python 风格的实用主义
- 数字显示清洗：0.1 + 0.2 怎么显示成 0.3（toPrecision(15) 的坑）
- 素材：闭包计数器示例、105 个测试里的求值部分

## 第 5 章：静态作用域解析 —— 让错误提前爆炸

- resolver 是干什么的：给每个变量引用算「隔几层」
- 为什么要预计算：性能只是其次，错误前置才是重点
  - return 出现在函数外 / break 出现在循环外
  - 同层重复声明 / `var x = x` 自引用
- 函数声明即时生效：递归为什么差点被「未初始化检查」误杀（真实 bug 复盘）
- 素材：4 类静态错误的测试

## 第 6 章：REPL 与工具链 —— 语言的第一印象

- 会话（Session）：为什么每行输入不能是独立程序
- 表达式回显的试探法：print 包裹 + 语句降级重试
- 多行续输入：哪些解析错误该「等下一行」，哪些该报错
- esbuild 打包单文件可执行
- 素材：REPL 交互实录（包括修坏的三个版本）

## 第 7 章：错误体验 —— 报错是语言的脸面

- 四阶段错误（词法/语法/作用域/运行时）统一成结构化对象
- 行列号从哪来：token 的起点记录原则
- 中文报错文案的尺度：亲切 vs 啰嗦
- 素材：错误信息改造前后对比

## 第 8 章：路线图与反思 —— 玩具的尽头是编译器

- 树遍历的性能天花板：fib(30) 耗时实测
- 字节码编译器 + 栈式 VM 预告（对照实验设计）
- 模板字符串歧义的解析器协同方案
- 教训清单：这个项目教会我的 10 件事
